Midnight Club 3: Recompilation

Traduzindo um clássico do PS2 para o PC nativo (Sem Emulador!)

A história de como pegamos um game lendário de 2004 e estamos reescrevendo ele peça por peça para rodar liso no computador. Um infográfico visual perfeito para roteiro de vídeo no YouTube!

ONDE ESTAMOS — 16/09/2026
  • Roda nativo: o jogo abre sem emulador, mostra a intro e a tela PRESS START BUTTON.
  • Velocidade: ~44,7 quadros por segundo (o PS2 roda a 60). O maior gasto é a parte que interpreta os comandos gráficos, maior até que o desenho em si.
  • Menu: depois do START a tela seguinte aparece, mas sem as opções. Medimos: o jogo cria 41 das 47 variáveis de tela do original — faltam as 6 que descrevem a lista de opções.
  • Funções que faltavam: zero. Todas as funções do caminho até o menu já foram reescritas conforme o jogo original e conferidas byte a byte.
  • Defeito visual aberto: a placa do menu aparece cortada na diagonal.
